# 1.2 머신러닝의 기본 용어

## 데이터 관련 용어
- **샘플(sample)**: 각각의 개별 데이터 사례
- **특성(feature)**: 샘플을 구성하는 속성들
- **특성 벡터**: 샘플을 수치로 표현한 벡터 형태
- **차원**: 특성의 개수

## 학습 관련 용어
- **훈련 데이터**: 모델 학습에 사용되는 데이터
- **가설/모델**: 학습을 통해 만들어진 규칙
- **예측**: 새로운 샘플에 대한 모델의 결과
- **레이블**: 실제 정답

## 학습 유형
- **지도 학습**: 정답이 있는 데이터로 학습
- **비지도 학습**: 정답 없이 패턴을 찾는 학습
- **분류**: 범주 예측 (예: 좋은/나쁜 수박)
- **회귀**: 연속값 예측 (예: 수박 당도)

## 핵심 목표
- **일반화**: 새로운 데이터에 대해서도 좋은 성능을 보이는 능력

# 2.1 경험 오차 및 과적합

## 기본 개념
- **오차율(error rate)**: 분류기가 잘못 분류한 샘플의 비율
- **정확도(accuracy)**: 분류기가 올바르게 분류한 샘플의 비율 (1 - 오차율)
- **훈련 오차(training error)**: 훈련 데이터에서의 오차
- **일반화 오차(generalization error)**: 새로운 샘플에서의 오차

## 과적합과 과소적합
- **과적합(overfitting)**: 훈련 데이터에만 과도하게 맞춰져 새로운 데이터에서 성능이 떨어지는 현상
- **과소적합(underfitting)**: 훈련 데이터조차 제대로 학습하지 못한 상태

## 모델 선택
- 과적합을 피하고 일반화 성능을 높이는 적절한 모델을 선택하는 것이 핵심
- 훈련 오차가 낮다고 해서 반드시 좋은 모델은 아님

# 2.2 평가 방법

## 홀드아웃 (Hold-out)
- 데이터를 훈련 세트와 테스트 세트로 분할
- 일반적으로 2/3~4/5를 훈련용, 나머지를 테스트용으로 사용
- 간단하지만 데이터 분할에 따라 결과가 달라질 수 있음

## 교차 검증 (Cross Validation)
- **k겹 교차 검증**: 데이터를 k개 부분으로 나누어 각각을 한 번씩 테스트 세트로 사용
- **LOOCV**: 샘플 개수만큼 분할하는 극단적인 경우
- 안정적이지만 계산 비용이 높음

## 부트스트래핑 (Bootstrapping)
- 복원추출로 여러 개의 부트스트랩 샘플을 생성
- Out-of-Bag 샘플을 테스트에 활용
- 데이터셋이 작을 때 유용

## 파라미터 튜닝
- **검증 세트(validation set)**: 모델 선택 및 파라미터 조정용
- 훈련/검증/테스트 세트로 3분할하여 사용
- 최종 성능은 테스트 세트에서만 평가

# 2.3 모델 성능 측정

## 오차율과 정확도
- **오차율**: 잘못 분류된 샘플 수 / 전체 샘플 수
- **정확도**: 올바르게 분류된 샘플 수 / 전체 샘플 수 = 1 - 오차율

## 정밀도, 재현율, F1 스코어
- **정밀도(Precision)**: 양성으로 예측한 것 중 실제 양성의 비율
- **재현율(Recall)**: 실제 양성 중 올바르게 예측한 비율
- **F1 Score**: 정밀도와 재현율의 조화평균

### 혼동행렬 기반 계산
- **TP**: 참 양성, **FP**: 거짓 양성
- **TN**: 참 음성, **FN**: 거짓 음성
- P = TP/(TP+FP), R = TP/(TP+FN)
- F1 = 2×P×R/(P+R)

## ROC와 AUC
- **ROC 곡선**: 거짓 양성률(FPR) vs 참 양성률(TPR) 그래프# 2.4 비교 검정

## 가설 검정
- **귀무가설**: 두 학습기의 성능이 같다
- **대립가설**: 두 학습기의 성능이 다르다
- 통계적 유의성 검정을 통해 성능 차이의 신뢰성 판단

## 교차 검증 t검정
- k겹 교차 검증 결과를 이용한 쌍체 t검정
- 자유도 k-1인 t분포 사용
- 5×2 교차 검증이 널리 사용됨

## 맥니마 검정
- 이진 분류 문제에서 두 분류기 비교
- 분할표를 이용한 카이제곱 검정
- 의견이 다른 경우에만 집중하여 분석

## 프리드만 검정과 네메니 사후 검정
- **프리드만 검정**: 여러 알고리즘의 전체적 성능 비교
- **네메니 사후 검정**: 개별 알고리즘 간 차이 분석
- 다중 데이터셋에서 여러 알고리즘 비교 시 사용
- **AUC**: ROC 곡선 아래 면적 (0.5~1.0, 클수록 좋음)
- 임계값에 무관한 성능 평가 가능

## 비용민감 오차율과 비용 곡선
- **비용 행렬**: 잘못된 분류에 따른 비용 정의
- **비용민감 학습**: 오분류 비용을 고려한 학습
- 클래스 불균형 문제 해결에 유용

# 2.5 편향과 분산

## 편향-분산 분해
- **편향(Bias)**: 학습 알고리즘의 기댓값과 참값의 차이
- **분산(Variance)**: 서로 다른 훈련 세트에 대한 학습 결과의 변화 정도
- **노이즈**: 데이터 자체의 불확실성

## 분해 공식
- 일반화 오차 = 편향² + 분산 + 노이즈

## 편향-분산 딜레마
- **편향이 높은 경우**: 과소적합 (모델이 너무 단순)
- **분산이 높은 경우**: 과적합 (모델이 너무 복잡)
- 편향과 분산을 동시에 줄이기 어려운 트레이드오프 관계
- 적절한 복잡도의 모델 선택이 중요

# 3.1 기본 형식

## 선형 모델의 기본 형태
- **일반형**: f(x) = w₁x₁ + w₂x₂ + ... + wₐxₐ + b
- **벡터형**: f(x) = wᵀx + b
- w = (w₁; w₂; ...; wₐ): 가중치 벡터
- b: 편향(bias) 항

## 선형 모델의 특징
- 속성들의 선형 조합으로 예측값 결정
- 해석이 용이하고 계산이 효율적
- 하지만 현실의 복잡한 비선형 관계 표현에 한계
- 선형 모델은 해석가능성(comprehensibility)이 뛰어남

# 3.2 선형 회귀

## 최소제곱법 (Least Square Method)
- **목표**: Σ(yᵢ - wxᵢ - b)²를 최소화
- 잔차의 제곱합을 최소화하는 w와 b 찾기

## 다변량 선형 회귀
- **행렬 형태**: w* = (XᵀX)⁻¹Xᵀy
- X: 설계 행렬 (각 행이 하나의 샘플)
- y: 목표값 벡터

## 정규화 기법
- **목적**: 과적합 방지와 수치적 안정성 향상
- XᵀX가 특이행렬인 경우 역행렬 계산 불가
- 정규화항을 추가하여 해결

## 로그 선형 회귀
- **형태**: ln y = wᵀx + b
- 지수적 관계를 선형으로 변환
- y = e^(wᵀx+b) 형태의 모델

# 3.3 로지스틱 회귀

## 기본 개념
- 선형 모델을 분류에 적용하기 위한 방법
- 시그모이드 함수를 이용해 확률값으로 변환

## 시그모이드 함수
- **함수**: y = 1/(1 + e⁻ᶻ)
- z = wᵀx + b일 때 0과 1 사이의 값 출력
- S자 곡선 형태로 부드러운 확률 변환

## 로짓(Logit) 함수
- **정의**: ln(y/(1-y)) = wᵀx + b
- 승산(odds)의 로그값
- 로그 오즈라고도 불림

## 최대우도법으로 학습
- **우도함수**: ℓ(w,b) = Σ ln p(yᵢ|xᵢ; w,b)
- 경사하강법이나 뉴턴법으로 최적화
- 볼록함수이므로 전역 최적해 보장

# 3.5 다중 분류 학습

## OvO (One vs. One)
- N개 클래스에 대해 N(N-1)/2개의 이진 분류기 훈련
- 각 분류기는 두 클래스만 구분
- 투표 방식으로 최종 결정

## OvR (One vs. Rest)
- N개 클래스에 대해 N개의 이진 분류기 훈련
- 각 분류기는 해당 클래스 vs 나머지 클래스 구분
- 가장 높은 점수를 받은 클래스 선택

## MvM (Many vs. Many)
- **ECOC (Error Correcting Output Codes)**: 오류 정정 출력 코드
- 각 클래스를 이진 코드로 표현
- 여러 이진 분류기의 조합으로 다중 분류 수행
- 오류 정정 능력을 통해 잘못된 예측 보완

## 클래스 불균형 문제
- 샘플 수가 매우 다른 클래스들 존재
- 언더샘플링, 오버샘플링, 리스케일링 등으로 해결
- 임계값 이동 기법도 효과적

# 3.6 클래스 불균형 문제

## 문제 정의
- 서로 다른 클래스의 샘플 수가 큰 차이를 보이는 상황
- 소수 클래스(minority class)에 대한 예측 성능 저하
- 단순히 다수 클래스로만 예측해도 높은 정확도 달성 가능

## 해결 방법

### 샘플링 기법
- **언더샘플링**: 다수 클래스 샘플 수 줄이기
- **오버샘플링**: 소수 클래스 샘플 수 늘리기
- **SMOTE**: 합성 소수 클래스 오버샘플링 기법

### 임계값 조정
- 분류 임계값을 이동하여 소수 클래스 인식률 향상
- ROC 곡선을 통한 최적 임계값 찾기

### 비용 민감 학습
- 오분류 비용을 다르게 설정
- 소수 클래스 오분류에 더 큰 패널티 부여
- 비용 행렬을 통한 학습 과정 조정
